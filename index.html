How the automation works

A GitHub Actions workflow in this repo (.github/workflows/job-search.yml) runs on a schedule (every 6 hours by default) and:

  • Searches Adzuna's free-tier job API for each title in your config.json, in your configured location
  • Sends each new posting to a free-tier LLM (Gemini or Groq — your choice) to score fit 0–10 against your real profile only
  • For postings that clear your fit threshold, asks the same model to build a tailored CV using ONLY your real, supplied bullets — never inventing anything
  • Commits the results to data/jobs.json, which this page reads — never regressing a stage you've already set

Set it up: fork this repo → add ADZUNA_APP_ID, ADZUNA_APP_KEY and LLM_API_KEY as repo secrets (Settings → Secrets and variables → Actions) → copy config.example.json to config.json with your real details (the Search settings tab can generate this for you) → commit it → enable GitHub Pages (Settings → Pages → Deploy from a branch) → enable Actions if prompted. Full walkthrough in the README.

Run now, on demand

This calls GitHub's API to trigger the job-search.yml workflow immediately, instead of waiting for the next scheduled run. It needs a personal access token with permission to trigger workflows in your own fork.

Security note: use a fine-grained token scoped only to this one repo, with just the "Actions: write" permission — never a broad classic token. It's stored only in this browser's local storage and is sent only to api.github.com, but any script that can read this page's local storage could read it too, so don't use this on a shared or public computer.
